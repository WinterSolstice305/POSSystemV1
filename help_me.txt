MINI SHOPPING CART HELP

Main menu:
- [1] Product management (add, edit, delete, view, search, or update stock)
- [2] Start a new transaction
- [3] View products
- [4] Search products by code or name
- [5] Show the current sales report
- [6] Exit
- [V] View, edit, remove, or check out cart items
- [H] Show this help screen

New transaction:
- Browse the catalog and add one or more products to the cart.
- After browsing, choose [Q] to continue to the cart and checkout.
- The product code and requested quantity are checked against available stock.

Viewing products:
- The catalog displays each product's code, name, price, and available stock.
- This menu only displays the catalog; choose [2] to start a transaction and add products.

Searching products:
- Enter any part of a product code or name; matching is case-insensitive.

Shopping cart:
- [C] Check out the cart.
- [E] Edit an item's quantity without exceeding available stock. Set it to 0 to remove the item.
- [R] Remove an item.
- [Q] Return to the main menu.

Checkout:
- Choose one discount: none, student (10%), senior citizen (20%), or PWD (20%).
- The receipt shows the transaction number, date, products, quantities, prices, subtotal, discount, total, payment, and change.
- Enter payment when prompted. Insufficient payment is rejected.
- Product stock is reduced and the cart is cleared after successful checkout.

Product and stock management:
- From the main menu, choose [1].
- [A] Add a product with a unique code, name, price, and stock.
- [E] Edit a product's name or price.
- [U] Update a product's stock.
- [R] Delete a product after confirming.
- [V] View products, [S] Search products, or [Q] Return to the main menu.
- Stock and price must be non-negative values. Product names and codes cannot be blank.
